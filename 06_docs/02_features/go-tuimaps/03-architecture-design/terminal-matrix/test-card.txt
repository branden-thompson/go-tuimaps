go-tuiMaps — TERMINAL TEST CARD

How to use: run   cat test-card.txt   in each terminal and font you use.
Every test row is a bar, 20 copies of one character, and a closing bar.
PASS = the closing bar sits exactly under the arrow (column 22), and the
character looks like what the label says. FAIL = the bar drifts left or
right (wrong width), or you see empty boxes, question marks or blanks
(the font lacks the character).
